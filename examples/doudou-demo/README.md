# doudou-demo · 随安装包分发的示例宠物

「豆豆」是一只橘猫，这个包是用 PawPal 的完整链路做出来的**示例宠物**：

- 参考图库：主人照片 → AI 重绘（绿幕设定图）→ Seedance 动作视频 → 本地抽帧拼表
- 两个动作：`idle`（待机，12 帧）与 `run`（奔跑，12 帧），单帧 512×512
- 精灵表转成 WebP（PNG 5.4MB → WebP 0.67MB），纹理总宽 6144px，远低于 16384px 上限

## 它会自动出现在哪

应用**首次启动且用户目录里一个宠物包都没有**时，主进程会把本目录复制到
`~/.petpet/pets/doudou-demo/` 并设为当前宠物——所以新装的应用打开就能看到一只猫，
而不是一片空白。

- 不想留着：托盘「🐕 切换宠物」换成别的，或直接删掉 `~/.petpet/pets/doudou-demo/`
- 已有自己的宠物时：**不会**再安装它（只在全空时触发，绝不覆盖用户数据）
