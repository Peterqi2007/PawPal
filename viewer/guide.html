📘 使用说明 从真实照片到会动的桌宠

核心链路四步：重绘形象 → 生成动作视频 → 抽帧拼表（可反复重抽）→ 装配应用。 前三步在图库里点，最后一步也在图库里点，装配完桌面立刻换成新形象。

0

先打开参考图库

托盘图标或桌宠右键 → 🖼 参考图库。

  • 每只宠物一个分组；分组里第一张照片自动成为设定图（锁定形象），其余是姿势参考图（只借姿态）。
  • 建议：设定图 1 张（正脸、全身、光线均匀）+ 姿势参考 3 张以上（站、坐、卧等）。
  • 图片只存在本地 ~/.petpet/refs/，单张最大 10MB。
1

重绘宠物形象

选好分组 → 点右下角 🎨 重绘设定图。

  • 会把「设定图 + 姿势参考」发给 AI，产出四边绿幕的风格化设定图（方便后续抠像）。
  • 耗时约 60–90 秒，按张计费；结果自动进分组并标记 AI 重绘。
  • 第一次用会要求填火山引擎密钥：只写在本地 ~/.petpet/ark.json（权限 0600），永不回显；不填则完全不联网。

不满意就再重绘一次——同一组可以有多张重绘结果，挑一张最像的「设为设定图」。

2

生成动作视频

在底部动作下拉里选动作（如「待机」）→ 点 🎬 生成动画。

  • 阶段会显示在按钮上：提交任务… → 云端渲染中 12s → 下载视频… → 抽帧拼表…。
  • 云端通常 1–3 分钟，按条计费；任务 ID 会落盘，超时后可补下载再本地重抽。
  • 完成后出现精灵表预览（横向整表按帧步进播放），并写入 ~/.petpet/anim/<宠物>/<动作>-source.mp4 与 -sheet.png。
  • 一动作一视频：8 个动作就要跑 8 次，建议先做「待机」看效果再决定要不要铺开。
3

重抽帧（不花钱的返工）

用已下载的视频重新抽帧拼表 → 点 ↻ 重抽帧。

  • 不消耗云端额度：视频已经在本地，只是重新跑「抽帧 → 抠像 → 拼表」。
  • 什么时候用：边缘有白边/残影、人物被裁掉、帧数不合适、换了抠像参数想对比。
  • 抽帧不满意先调设定图的绿幕质量（重绘一次往往比反复调参更有效）。
4

装配到桌宠（实际应用）

图库中部 📦 装配当前分组。

  • 产物写入 ~/.petpet/pets/<宠物 id>/：pet.json（v3 契约）+ 各动作精灵表。
  • 重名会自动加序号；装配完成后自动切换到这只宠物，桌面立刻看到新形象。
  • 之后随时可换回：托盘 🐕 切换宠物。
  • 红线：单张精灵表 帧数 × 单帧宽 ≤ 16384px（WebGL 单轴上限），超了整窗会黑屏。
5

检查清单

  • 设定图是四边绿幕、背景干净（没有渐变/阴影/杂物）
  • 每个动作都有 *-source.mp4 与 *-sheet.png，且后者不比前者旧
  • 装配后托盘「切换宠物」里能看到新宠物，且动作能正常切换
  • 桌宠卡顿时先看单表宽度是否接近 16384px

常见问题

按钮一直停在「云端渲染中」
云端排队，按钮上会持续显示已等待秒数；超过 5 分钟可取消重试，任务已落盘可稍后补下载。
抽出来有白边 / 毛边
先用 ↻ 重抽帧 试一次；仍不行就重绘设定图，让绿幕更纯净。
装配完桌面没变化
托盘 🐕 切换宠物 里确认选中的是新宠物；必要时重启一次。
要花多少钱
重绘按张、视频按条计费，平台侧扣额度；重抽帧、装配、切换宠物都是本地操作，不花钱。
不想联网
不填密钥即可：图库、手动素材、重抽帧、装配全部照常，只是不能重绘和生成视频。

更细的原理与参数见仓库 docs/05-素材管线.md、docs/08-接口协议.md。
