## 说明

1. **三层含义**：Schema = 契约字段存在；Runtime = 渲染进程消费；Viewer = 主进程消费（菜单/安全/导入等）。
2. **「完成」的定义**：字段进契约 + 被消费 + 有测试或实测证据（见 13-验证台账-20260810.md）。
3. **审计速查**：先看本表找目标能力的「状态」列，再按「证据」列定位代码；如发现本表与代码不符，以代码为准并修正本表。
4. **验证 commit 列**：该能力最近一次实现/验证对应的提交 hash，用于追溯证据链；多 commit 时列出全部相关。
5. **Last verified commit**：`cf5d071`（2026-08-10 测试资产入库，本表最后一次全面核对；此后任何代码变更应先更新本表再合入）。
