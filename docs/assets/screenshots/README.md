## 补图时注意

- **桌宠是透明置顶窗口**，截屏要整屏截（不要用窗口截图，否则透明区变黑底）
- 截图前把数值调成非满值（如 饱腹 70 / 心情 85），胶囊和情绪表现才都有内容
- 专注态想让桌宠同时变暗：先在托盘开专注，再截图
- 宽度超过 1600px 建议缩到 1600（README 里表格单元格约 400px 宽，再大只是浪费体积）
- 单张尽量 < 1MB；本目录目前合计约 2.4MB（仓库有 25MB 体积红线）
- 一律 PNG；演示动图放 `assets/`，不要放这里
